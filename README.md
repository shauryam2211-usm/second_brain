Second Brain

A backend API for a Second Brain application that allows users to securely store, manage, and share their digital content.

Features
User signup and authentication
JWT-based authentication
Create content
Get saved content
Delete content
MongoDB database integration
Share your brain using a unique share link
Protected API routes using authentication middleware
Tech Stack
Node.js
TypeScript
Express.js
MongoDB
Mongoose
JWT (JSON Web Tokens)
tsx
